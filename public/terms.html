1. About Habit Tracker

Habit Tracker is an educational web application created as part of a university software security project.

The application allows users to create habits, monitor progress, participate in challenges, and interact with shared habits.

These terms describe expected use of the demonstration application. They are not a complete, legally reviewed commercial service agreement.

2. User Accounts

Some features require users to register and sign in with their own accounts.

  • Use your own account and do not impersonate another user.
  • Keep your login credentials confidential.
  • Do not attempt to access accounts, records, or administrator functions without authorization.
  • Report suspected security issues privately to the project maintainers.

3. Habit Tracking

Users can create and manage their own habits, record check-ins, monitor streaks, and review progress statistics.

Habit Tracker supports daily schedules, selected weekdays, and weekly goals. Some habits may include measurable targets.

The application is intended for personal organization and educational use. It does not provide professional medical, psychological, or financial advice.

4. Public and Private Content

Users can choose whether individual habits are private or shared with other users.

  • Public habits can be viewed by authenticated users.
  • Private habits are not visible to other regular users.
  • Check-in records, notes, and proof photos are not shared through public habit records.
  • Authorized administrators have additional access for moderation and administration.

Users should avoid including confidential or sensitive personal information in publicly shared habit descriptions.

5. Community Guidelines

Habit Tracker includes community features such as comments, reactions, following, and optional challenges.

Users are expected to interact respectfully and avoid:

  • Harassment or abusive behavior.
  • Spam and misleading content.
  • Impersonation of other users.
  • Unauthorized disclosure of personal data.
  • Malicious links or attempts to exploit the application.

Administrators can remove content and manage accounts using the permissions provided by the application.

6. Security and Acceptable Use

The application includes authentication, authorization, input validation, rate limiting, and other security controls.

Users must not attempt to bypass access restrictions, interfere with other users' information, or disrupt the application's normal operation.

Security vulnerabilities should be reported privately rather than publicly disclosing sensitive implementation details.
