LEGAL & PRIVACY

Privacy Policy

Your habits are personal. This page explains how Habit Tracker handles information within this educational application.

Last updated: October 31, 2026

1. About This Project

Habit Tracker is an educational web application developed as part of a university security project. It allows users to create habits, track progress, and optionally share selected habits with others.

This document describes the application's documented features and data handling. It is a demonstration privacy notice and is not a complete production privacy policy.

2. Information We Handle

Depending on how you use Habit Tracker, the application may process:

  • Account information, including username, email address, and password verification data.
  • Habit information, including titles, descriptions, categories, schedules, and measurable goals.
  • Check-in history, notes, and optional proof photographs.
  • Community interactions, including comments, reactions, following activity, and challenge participation.
  • Progress information, including streaks, statistics, badges, and reminders.

Passwords are stored as cryptographic hashes, rather than readable plaintext passwords.

3. How Information Is Used

The application processes information to:

  • Authenticate users and maintain sessions.
  • Create and manage personal habits.
  • Record check-ins and calculate progress.
  • Display statistics, streaks, and achievements.
  • Support optional community interactions.
  • Apply access controls and security protections.

4. Who Can See Your Data?

Habit Tracker distinguishes between private information and information intentionally shared through public habits.

  • Private habits are accessible to their owner and authorized administrators.
  • Public habits can be viewed by other authenticated users.
  • Check-ins, notes, and proof photographs remain private from other regular users, including when the associated habit is public. Administrators have documented access.
  • Reminder times are available only to the habit owner.
  • Challenge leaderboard information is shared according to the application's participation and consent settings.

5. Security Measures

Habit Tracker includes security controls designed to protect user accounts and application data.

  • Password hashing using bcrypt.
  • Authenticated sessions and protected cookies.
  • Server-side input validation.
  • Record-level access authorization.
  • Rate limiting for sensitive operations.
  • CSRF and injection protections.
  • Security headers and Content Security Policy.

These safeguards are part of the educational application's design. No system can guarantee absolute security.

6. Authentication Cookies

Habit Tracker uses an authentication cookie to maintain signed-in sessions.

The session cookie is configured with HttpOnly and SameSite=Strict protections, and the Secure attribute is enabled in production.

7. Third-Party Services

The Contact page may display an embedded map provided by OpenStreetMap.

Loading this map connects the browser to an external service, which may receive technical request information according to its own privacy practices.

The map location is provided for demonstration purposes and does not represent an actual Habit Tracker office.

8. Your Information and Available Controls

Users can manage their habits and choose whether individual habits are shared publicly.

Habit Tracker also provides a personal data export feature. The documented export excludes password hashes and photograph file contents.

Questions about access, correction, deletion, or other data-related requests should be directed privately to the project maintainers. Available procedures and applicable legal rights depend on the deployment and its operator.

9. Data Retention

The application uses database storage for account information, habits, check-ins, and related records.

A complete production retention schedule, backup policy, and deletion procedure have not been established in this educational notice. These must be verified before production use.

10. Updates to This Notice

This notice may be updated as the application and its documented data handling change. The revision date will be updated accordingly.

11. Contact

For privacy-related questions about this educational project, contact the repository maintainers through the established project communication channels.

Do not post passwords, session tokens, or other sensitive information in public issues.
